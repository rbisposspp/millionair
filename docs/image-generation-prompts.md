Use these prompts for the 50 curated image assets in `docs/media-assets.md`. Each image should be realistic, modern, fancy, and classroom-safe. Keep the palette consistent: light blue, medium pink, and dark purple. Subtly embed the text `RBS Tech Teach` within a natural scene element such as a notebook cover, wall poster, tote bag, classroom label, receipt, badge, sign, or device sticker. Do not make the embedded text the main subject.
