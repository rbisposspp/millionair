# Media Asset List

This checklist describes the curated media files expected by the seed question bank. Upload these files to the bucket configured by `MEDIA_BUCKET` using the exact `storagePath` values below.

## Production Guidelines

- Images: PNG, 16:9, recommended 1280x720, classroom-safe, realistic or friendly illustrated style, no text overlays.
- Audio: WAV, clear voice, neutral classroom-friendly accent, light natural pacing, no background music, 18-28 seconds.
- Content must match the CEFR level. A1/A2 should be concrete and short; B1-C1 can include more detail, inference, and nuance.
- Each media file should support speaking practice, not replace Bobby's teacher-led interaction.
